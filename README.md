## 🌟 أبرز مميزات المشروع (Key Features)

### 🎨 1. صانع البراوني التفاعلي (Interactive Brownie Builder)
- تخصيص كامل للبراوني: اختيار القاعدة (كلاسيك فدج، تريبل شوكليت، كيندر، لوتس، ريد فيلفيت، إلخ).
- اختيار أنواع صوص الشوكولاتة البلجيكية الساخنة (بلجيكي داكن، حليب، أبيض، بستاشيو، كراميل مملح).
- إضافة توبينجز وفواكه ومكسرات مع تحديث فوري وسلس لمعاينة المنتج.
- حساب ديناميكي تلقائي للسعر الإجمالي والسعرات الحرارية (Calories Counter) في كل خطوة.

### 🛒 2. سلة مشتريات ديناميكية ونظام دفع (Cart & Smart Checkout)
- إضافة المنتجات الجاهزة أو المبتكرة مع حفظها تلقائياً في `localStorage`.
- تعديل الكميات وحذف العناصر وحساب الضريبة وكوبونات الخصم ورسوم التوصيل بالرياض.
- واجهة دفع سهلة تدعم طرق دفع متعددة (Apple Pay، بطاقات مدى / فيزا، الدفع عند الاستلام).
- تحديد موقع وتفاصيل التوصيل ووقت الاستلام المرغوب.

### 🤖 3. المساعد الذكي التفاعلي (AI Chatbot Assistant)
- شات بوت مدمج ذكي للإجابة على استفسارات العملاء الشائعة.
- اقتراح نكهات وخلطات براوني مخصصة بناءً على ذوق وتفضيلات العميل.
- إمكانية طلب المساعدة الفورية بضغطة زر وتجربة محادثة سلسلة ومباشرة.

### 📊 4. لوحة تحكم الإدارة والمطبخ (Owner & Kitchen Dashboard)
- واجهة إدارة متكاملة لمتابعة الطلبات المباشرة وحالاتها (قيد التحضير، في الفرن، جاري التوصيل، مكتمل).
- إحصائيات المبيعات والأرباح اليومية، والمنتجات الأكثر طلباً.
- إمكانية الدخول السريع عبر الرابط `admin.html` أو عبر تفعيل وضع المالك `?admin`.

### 📱 5. تطبيق ويب تقدمي متجاوب (PWA Ready & Responsive UI)
- دعم التثبيت المباشر على الهواتف والأجهزة الذكية كأنه تطبيق أصلي عبر `manifest.json`.
- دعم التصفح والعمل بدون اتصال بالإنترنت عبر `sw.js` (Service Worker).
- تصميم متجاوب فائق الدقة والأناقة (Dark & Modern Theme) متوافق مع كافة مقاسات الشاشات.

### 🔊 6. مؤثرات صوتية وتفاعلية (Audio FX & Micro-interactions)
- نظام مؤثرات صوتية مخصص عبر Web Audio API للتفاعل مع الأزرار والإضافات وإتمام الطلب.
- تحكم كامل بالصوت (تشغيل/كتم) بضغطة زر واحدة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **HTML5 (Semantic)** | البنية الهيكلية وتوافق محركات البحث وسهولة الوصول (Accessibility). |
| **CSS3 & Modern Design System** | تصميم واجهات حديثة بتأثيرات Glassmorphism، متغيرات CSS، ورسوم متحركة سلسة. |
| **Vanilla JavaScript (ES6+)** | المنطق البرمجي، إدارة الحالة (State Management)، التخزين المحلي `localStorage`، والتفاعل بدون مكتبات خارجية ثقيلة. |
| **Service Workers & PWA** | إتاحة التثبيت على الهاتف وتخزين الملفات للعمل دون اتصال بالإنترنت. |
| **Web Audio API** | مؤثرات وتغذية راجعة صوتية تفاعلية. |
| **FontAwesome 6** | الأيقونات التفاعلية الموحدة في كل صفحات التطبيق. |
| **Python 3** | خادم محلي خفيف لاختبار ومحاكاة تشغيل التطبيق. |

## 📂 هيكل المجلدات والملفات (Project Structure)

```text
brownie-craft-system/
│
├── index.html              # الصفحة الرئيسية للمتجر وتطبيق الويب
├── admin.html              # لوحة تحكم وإدارة الطلبات والمطبخ
├── README.md               # التوثيق الشامل للمشروع
├── manifest.json           # ملف تعريف تطبيق الويب التقدمي (PWA Manifest)
├── sw.js                   # Service Worker للكاش والعمل بدون إنترنت
├── server.py               # سيرفر محلي خفيف عبر بايثون
│
├── assets/
│   ├── css/
│   │   └── style.css       # نظام التصميم، الألوان، والتنسيقات الكاملة
│   ├── icon-192.png        # أيقونة PWA بمقاس 192x192
│   └── icon-512.png        # أيقونة PWA بمقاس 512x512
│
└── js/
    ├── app.js              # نقطة البداية وإدارة التنقل والتهيئة العامة
    ├── customizer.js       # منطق صانع ومخصص البراوني التفاعلي
    ├── cart.js             # منطق إدارة السلة، الحسابات، والحفظ
    ├── checkout.js         # منطق إتمام الطلب والتحقق وتأكيد الدفع
    ├── chatbot.js          # المساعد الذكي الآلي للمحادثات
    ├── admin.js            # لوحة تحكم صاحب المتجر وتحديث الطلبات
    ├── data.js             # مصفوفات البيانات، المكونات، والمنتجات
    └── audio.js            # نظام المؤثرات الصوتية التفاعلية
```

## 🚀 طريقة التثبيت والتشغيل محلياً (Getting Started)

### المتطلبات الأساسية
- أي متصفح حديث (Chrome, Edge, Safari, Firefox).
- اختياري: تثبيت Python 3 لتشغيل السيرفر المحلي.

### خطوات التشغيل:

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/username/brownie-craft-system.git
   cd brownie-craft-system
   ```

2. **تشغيل الخادم المحلي عبر بايثون:**
   ```bash
   python server.py
   ```

3. **فتح التطبيق في المتصفح:**
   - **صفحة المتجر الرئيسية:** [http://localhost:8000](http://localhost:8000)
   - **لوحة تحكم الإدارة والمبيعات:** [http://localhost:8000/admin.html](http://localhost:8000/admin.html)

> [!TIP]
> يمكنك أيضاً فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح دون الحاجة لأي أدوات إضافية.
